# KARO ceramics

Website for KARO ceramics: hand-thrown landmark tumblers made in the Bay Area.

- `site/`: the website (plain HTML/CSS, no build step). Every push to `main` deploys it to GitHub Pages.
- `brand/`: logo files.

Shop: https://www.etsy.com/shop/CeramicsbyKaro · Instagram: https://www.instagram.com/ceramics_by_karo/
